AeroSense

AI-Powered Air Quality Prediction & Visualization System

Full-stack air-quality platform predicting AQI and visualizing pollution data across five major Indian metro cities (Mumbai, Delhi, Bengaluru, Kolkata, Chennai). Provides citizens and researchers with forecasting and actionable advisories.

01/

Random Forest Predictions: Trained ML regressor estimating PM2.5, PM10, NO2, and composite AQI indices with cross-validation against historical seasonal fluctuations.

02/

CPCB Classification & Health Advisory: Algorithmic categorization into Central Pollution Control Board safety tiers with dynamic alerts for sensitive groups.

03/

City-Wise Trends & Pollutant Analytics: Multi-pollutant charting across Indian metros powered by responsive Recharts vectors.

CorpusAI

AI-Powered Financial Lifecycle Planning System

Interactive dashboards, secured APIs, and modular ML pipeline for personalized financial and retirement planning. Synthesizes demographic, liability, and risk appetite indicators into structured accumulation roadmaps.

01/

Six-Stage ML Pipeline: Features XGBoost predictive modeling, LSTM sequential compounding models, K-Means behavioral clustering, and Isolation Forest anomaly screening for risk detection.

02/

Financial & Retirement Dashboards: Interactive simulations driven by Zustand client stores and Recharts multi-tier timeline projections with dynamic contribution tuning.

03/

Four Services with Docker Compose: Multi-container setup harmonizing the frontend, Node.js API gateway, FastAPI ML engine, and MongoDB instances.
